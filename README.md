# TaskTrack

TaskTrack is a simple command-line program that lets users manage tasks.

## Current Features
- Add tasks
- View tasks

## Running the Program
Run this in the terminal:
python tasktrack.py

## Current Limitation
Tasks are not saved. They disappear when the program closes.
How It Works
Tasks are stored in a list while the program is running.
Users can add tasks, view their tasks and exit the program.
